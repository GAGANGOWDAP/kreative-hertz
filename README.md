# Kreative Hertz — Wealth Architect & Life Strategist
> **Complexity 2 Simplicity**

A modern, high-performance financial advisory web platform built with **Next.js 16**, **React 19**, **TypeScript**, and **Tailwind CSS**.

---

## 🌟 Overview & Core Services

Kreative Hertz delivers transparent, fiduciary financial architecture, transforming complex policies into clear, confident decisions across four core domains:

1. **🛡️ Insurance Protection**
   - Life Insurance (Pure Term & Living Benefits)
   - Health Insurance (High-Restoration & Cashless Networks)
   - Vehicle / Auto Insurance (Zero Depreciation & Roadside Assistance)
   - Travel Insurance (Global Medical & Visa-Compliant Cover)
   - Group Health Insurance (Corporate Wellness)
   - Commercial Insurance (Asset, Marine, Fire & Executive Liability)

2. **📈 Investments & Wealth**
   - Mutual Funds & Systematic Investment Plans (SIP)
   - Financial Planning & Goal-Based Mapping
   - Wealth-Building Guidance (*Wealth Architect Advisory*)

3. **💳 Loans & Financing**
   - Personal Loans
   - Business Loans (MSME & Working Capital)
   - Home Loans (Lowest Interest & Balance Transfers)
   - Loan Against Property (LAP)

4. **🧭 Life Strategy & Consulting**
   - Unbiased Fiduciary Consulting
   - **The 3 Foundational Pillars**:
     - 🧠 **Mindset**: Long-term vision and emotional discipline.
     - ⚖️ **Moral**: 100% fiduciary ethics and zero hidden commissions.
     - 🔍 **Awareness**: Total clarity over policy terms and compounding mechanics.

5. **🎓 Learn & Earn Ecosystem**
   - **Learn**: Practical Financial Education, Insurance Literacy, and Investment Basics.
   - **Earn**: Transparent Freelance, Part-Time, and Wealth Architect Career Pathways.

---

## 🚀 Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) 16 (App Router)
- **UI & Components**: [React 19](https://react.dev/), [Lucide React Icons](https://lucide.dev/)
- **Styling**: Vanilla Tailwind CSS & Custom Obsidian/Teal Neon Theme
- **Language**: TypeScript

## 🛠️ Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/ankithr564/Kreative_Hertz.git
   cd Kreative_Hertz
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
